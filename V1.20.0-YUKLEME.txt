İLAN ŞEHRİ v1.20.0 — GÜVENLİ RANDEVU VE TESLİM PLANLAMA
===============================================================

TABAN SÜRÜM
- v1.19.0.2

YÜKLEME
1. Bu ZIP dosyasını çıkarın.
2. İçindeki klasör ve dosyaları mevcut İlan Şehri proje ana klasörüne kopyalayın.
3. Var olan dosyaların değiştirilmesini onaylayın.
4. GitHub Desktop özetine şunu yazın:
   İlan Şehri v1.20.0 güvenli randevu ve teslim planlama
5. Commit to main ve Push origin yapın.
6. Django Kontrol ile Mobil Görsel Denetim sonuçlarının ikisinin de yeşil olmasını bekleyin.
7. İki denetim de yeşil olduktan sonra Codespaces terminalinde:

   git pull origin main
   pkill -f "manage.py runserver" || true
   bash scripts/start_codespace.sh

ÖNEMLİ
- Güncelleme Appointment tablosunu ekler.
- start_codespace.sh, üretim kurulum betiği ve GitHub Actions ensure_v120_schema komutunu otomatik çalıştırır.
- Randevu yeri, notu ve taraf bilgileri yalnız ilgili alıcı ile satıcıya gösterilir.
- Gerçek sunucuda günlük marketplace_maintenance zamanlayıcısı hatırlatmaları gönderir.
