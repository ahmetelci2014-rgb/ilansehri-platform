# İlan Şehri v1.22.0 denetim raporu

## Kapsam

v1.22.0; yeni bir yan iş modeli eklemeden ana sayfa, kategori merkezi, ilan kartları, ilan verme sihirbazı ve mobil görsel düzeni güçlendirir.

## Tamamlanan kontroller

- Python `compileall`: başarılı
- Değişen Python dosyaları `py_compile`: başarılı
- Tüm JavaScript dosyaları `node --check`: başarılı
- Bash dosyaları `bash -n`: başarılı
- JSON dosyaları: başarılı
- CSS blok dengesi: başarılı
- Django şablon işaret dengesi: başarılı
- Bağımlılıksız mobil sözleşme kontrolü: başarılı
- Güncelleme paketi temiz v1.21.0.1 tabanına uygulanıp tam kaynakla karşılaştırılacak
- ZIP CRC/bütünlük kontrolü paketlemeden sonra çalıştırılacak

## Eklenen sözleşmeler

- Ana sayfa profesyonel kategori merkezi: `data-v122-category-hub`
- İlan kartı sözleşmesi: `data-market-card`
- İlan verme ilerlemesi: `data-v122-wizard-progress`
- Yayın öncesi kontrol listesi: `data-v122-review-checklist`
- v1.22 CSS ve JavaScript dosyaları ortak kabuk ve service worker önbelleğine bağlandı

## Mobil denetim

Mobil Görsel Denetim; üç telefon genişliğinde kamu, alıcı, satıcı, görev ortağı ve yönetim ekranlarını gezer. Emlak ve hizmet kategori açılışlarının eklenmesiyle beklenen kapsam **144 ekran kombinasyonudur**.

## Veritabanı

- Yeni tablo yoktur.
- Yeni model alanı yoktur.
- Migration gerekmez.
- Mevcut ilan, kullanıcı, randevu ve görev ortağı verileri değiştirilmez.

## GitHub Actions doğrulaması

Bu çalışma ortamında Django ve Playwright bağımlılıkları kurulu olmadığı için tam Django testleri ile gerçek Chromium ekran taraması yerelde çalıştırılamadı. Yüklemeden sonra **Django Kontrol** ve **Mobil Görsel Denetim** iki ayrı zorunlu doğrulama olarak çalışacaktır.
