İLAN ŞEHRİ v1.4 — TASARIM DÜZELTME VE RESPONSIVE KALİTE TURU

1. Bu ZIP dosyasını ayıklayın.
2. İçindeki bütün dosya ve klasörleri GitHub Desktop'taki ilansehri-platform klasörüne kopyalayın.
3. Hedefteki dosyaları değiştirin.
4. GitHub Desktop Summary:
   İlan Şehri v1.4 tasarım düzeltmeleri
5. Commit to main ve Push origin.
6. GitHub Actions yeşil olduktan sonra Codespaces terminalinde:
   git pull origin main
   pkill -f "manage.py runserver" || true
   bash scripts/start_codespace.sh
7. Port 8000'i açın.
8. Ctrl + Shift + R ile önbelleksiz yenileyin.

Önemli:
- Bu sürüm veritabanını ve iş mantığını değiştirmez.
- Düzeltmeler ayrı static/css/v14-polish.css dosyasındadır.
- Kalan görsel sorunlarda sayfanın tam ekran görüntüsü yeterlidir.
